## Replacing a placeholder

1. Capture the actual Unreal Editor behavior or create a source-accurate diagram described in this inventory.
2. Save it at `docs/assets/media/` using the row's exact final filename.
3. Replace that figure's placeholder `<img src>` with a relative path to the new file; keep its reader caption true to the final image.
4. The capture-instruction line may remain during documentation production, but remove it deliberately when the final site is ready for public-facing-only captions.
5. Check actual GitHub Pages rendering, image width, animated timing, alt text and responsive layouts.

The machine-readable registry is [media-slots.json](assets/media-slots.json).
